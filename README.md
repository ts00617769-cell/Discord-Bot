# ⚔️ Prasia-Discord-Bot (波拉西亞戰記公會助手)

這是一款專為《波拉西亞戰記》公會設計的 Discord 多功能機器人。專注於公會自動化管理、首領戰時程掌控以及增進成員社群互動。

---

## 🌟 核心功能

### 1. 🕒 首領重生自動提醒 (Boss Reminder)
* **精準預警**：背景任務每分鐘掃描一次，並在首領重生前 **10 分鐘** 自動發送頻道廣播。
* **自動化運維**：基於 `discord.ext.tasks` 實現，無需任何手動輸入，確保公會成員準時集結。

### 2. 🎲 全自動深層心理測驗 (Psychology Quiz)
* **每日排程**：
    * **中午 12:00**：自動從 50 題 Kokology 題庫中抽取題目發布，並開啟隱藏式投票。
    * **晚上 18:00**：自動結算當日數據，公布解析並揭曉所有人的選擇。
* **盲投機制**：成員投票過程完全保密，增加晚間開獎時的趣味性與話題性。
* **日期種子演算法**：使用當前日期作為隨機控制碼，確保當日題目唯一，且重複呼叫時不會洗掉既有票箱。

## **📜 指令清單**

---

| 指令 | 說明   |
| :---- | :---- |
| \!定時測驗 | 手動觸發今日盲投題目 (12:00 會自動執行) |
| \!測試開獎 | 立即結算當前投票 (18:00 會自動執行) |
| \!測驗 | 隨機發送一則即時心理測驗 (不含盲投紀錄) |

## **📁 檔案結構**

* ---

  bot.py: 核心邏輯、背景排程與按鈕互動。
