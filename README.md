# 🤖 波拉西亞戰記 Discord 戰情機器人 (Wars of Prasia Bot)

這是一個專為《波拉西亞戰記》量身打造的高效能 Discord 機器人。具備全異步 (Asynchronous) 架構，提供即時的戰情數據掃描、經驗值測速雷達、宇宙聯賽追蹤，以及多樣化的互動娛樂功能，是旅團與戰情室不可或缺的最佳輔助終端機。

## ✨ 核心特色功能

### 📊 戰情與數據掃描 (Intel & Data Tracking)
* **🏆 即時排名與歷史快照**：透過 API 串接，即時取得全服或單一伺服器的玩家排名，並支援職業篩選與歷史資料庫調閱。
* **🏎️ 經驗值測速雷達**：全自動背景掃描前 50 名玩家經驗值，提供精準的「練功時速」計算，並支援手動測速 (`!測速`)。
* **🚨 飆車超速警報**：自動偵測時速超過設定門檻 (預設 4000 億) 的玩家，並發送警報至指定頻道，嚴密監控敵對陣營動態。
* **🌌 宇宙聯賽觀測站**：輸入賽季與回合，自動生成排版精美的各陣營與公會貢獻分數報表 (`!聯賽`)。
* **🏰 據點稅收掃描**：一鍵查詢各伺服器據點的鑽石與紅寶石累積稅收 (`!稅收`)。
* **✨ 星光解放出席點名**：自動統計特定時段內，經驗值增幅符合條件的活躍玩家清單。
* **🗡️ 討伐等級排行**：查詢全服前 100 名討伐等級排行 (`!討伐排名`)。
* **🕵️ 尋人與轉服掃描**：利用經驗值特徵，精準追蹤改名或轉服的玩家 (`!尋人`, `!轉服掃描`)。
* **⏳ 時間隙縫戰報**：查詢時間隙縫(交叉王)首領擊殺與MVP戰報 (`!時空王`)。

### 🎲 互動與遊戲輔助 (Entertainment & Tools)
* **🔮 運勢與占卜**：支援抽取今日大阿爾克那塔羅牌 (`!塔羅`)、線上廟宇求籤，以及結合即時網路爬蟲與資料庫快取的真實每日星座運勢 (`!星座`)。
* **⚒️ 鍊成模擬器**：模擬遊戲內四合一裝備鍊成機率，挑戰連過四柱的快感 (`!鍊成`)。
* **🧠 每日深層心理測驗**：支援定時發布「盲投心理測驗」，玩家投票後資料庫自動持久化儲存，並於指定時間自動開獎 (`!測驗`)。
* **🕒 時空縫隙提醒**：根據每日排程，自動於首領召喚前 10 分鐘發送 `@everyone` 提醒。

### 🛠️ 專業級系統架構 (Advanced Architecture)
* **非同步資料庫 (`aiosqlite`)**：全面採用非同步 SQLite，支援批次寫入 (`executemany`)，即使面對大量數據依然保持極速效能。
* **全域網路連線池 (`aiohttp`)**：統一管理 API 請求連線，降低 TCP 握手延遲，並具備防爬蟲阻擋機制。
* **熱重載系統 (Hot Reload)**：開發者專屬的 `!reload` 指令，修改程式碼後無須重啟機器人即可套用更新。
* **斷電接關與容錯機制**：排程任務具備 `try...except` 雙重保護，即使網路瞬斷也能自動重試；進行中的測驗狀態不怕伺服器重啟。
* **頻道資安防護**：測速 / 排名 / 尋人等機密指令僅限 `ALLOWED_COMMAND_CHANNELS`；未設定時 fail-closed。`!聯賽`、`!討伐排名`、`!稅收`、`!時空王` 為公開指令。
* **伺服器探活**：擁有者可用 `!伺服器檢查` 對照官網 Ranking API 驗證 `SERVER_MAP`（資料來源 [warsofprasia.beanfun.com](https://warsofprasia.beanfun.com/)）。

## 🚀 安裝與啟動教學

### 1. 系統需求
* Python 3.8 或以上版本
* 穩定連線的網路環境

### 2. 安裝依賴套件
請在專案根目錄下，開啟終端機並執行以下指令來安裝所需的 Python 套件：
```bash
pip install -r requirements.txt
(主要包含：discord.py, aiohttp, aiosqlite, pytz, beautifulsoup4, python-dotenv 等)
3. 環境變數設定
請將專案中的 .env.example 重新命名為 .env，並填入您的專屬設定：
# 機器人 Token (必填)
DISCORD_TOKEN=你的機器人Token填這裡

# 戰情機密指令允許使用的頻道 ID (多個請用逗號分隔)
ALLOWED_COMMAND_CHANNELS=123456789012345678,987654321098765432

# 經驗值超速警報發送頻道
EXP_ALERT_CHANNEL_ID=123456789012345678

# 時空縫隙首領提醒頻道
BOSS_REMINDER_CHANNEL_ID=123456789012345678

# 每日心理測驗發布頻道
QUIZ_CHANNEL_ID=123456789012345678

4. 啟動機器人
設定完成後，輸入以下指令啟動機器人：
python bot.py
若終端機顯示 🤖 [你的機器人名稱] 已成功登入 Discord 並準備就緒！ 且各模組皆顯示掛載成功，即代表啟動完畢！
